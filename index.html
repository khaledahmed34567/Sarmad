اختصارات لوحة المفاتيح العالمية

تحكم سريع واحترافي في كامل منصة سرمد عبر لوحة المفاتيح

الاختصارات العامة الأساسية

فتح لوحة الأوامر والبحث الفوري Ctrl + K / ⌘ + K
فتح مساعد سرمد الذكي السريع Ctrl + Shift + A
فتح المعامل البرمجية التفاعلية Ctrl + Shift + L
عرض نصيحة برمجية يومية عشوائية Ctrl + Shift + T
إظهار دليل اختصارات لوحة المفاتيح Ctrl + / أو ?
إغلاق أي نافذة منبثقة أو لوحة مفتوحة Esc

اختصارات داخل المعامل البرمجية (Coding Labs)

تشغيل الكود البرمجي فوراً (Run Code) Ctrl + Enter / ⌘ + Enter
حفظ الكود البرمجي في المتصفح محلياً Ctrl + S / ⌘ + S
فحص وتصحيح الكود بالذكاء الاصطناعي (AI Review) Ctrl + Shift + E
إعادة ضبط الكود إلى القالب المبدئي Ctrl + Shift + R
المسافة البادئة في المحرر (Indentation) Tab / Shift + Tab

اختصارات التنقل الفوري بين أقسام سرمد

الصفحة الرئيسية Alt + 1
مسارات التعلم والبرمجة Alt + 2
المعامل البرمجية التفاعلية Alt + 3
لوحة تحكم الطالب (لوحتي) Alt + 4
لوحة المتصدرين Alt + 5
المقالات البرمجية والتقنية Alt + 6
تعمل الاختصارات مع أنظمة Windows و macOS و Linux.
